# HW54 · Codec Lab

Реализация исходного nodejs-hw01-tests: определение debug-режима, кодирование и декодирование Base64/Hex на Buffer, безопасная проверка формата.

isDebugMode сравнивает NODE_ENV строго с development, логирует значение среды и результат. Кодировщики объединяют аргументы через двоеточие. Обычные декодировщики используют поведение Buffer, безопасные — проверяют стандартный Base64 с padding и каноничными неиспользуемыми битами либо Hex с чётным числом цифр. Пустая строка допустима, Hex нечувствителен к регистру. URL-safe Base64 и строки с пропущенным padding не принимаются безопасным декодером. Преобразование байтов в текст использует обычное поведение UTF-8 Buffer.

При невалидном формате safe-функции логируют и выбрасывают точные сообщения Invalid base64 string / Invalid hex string. Кодирование не является шифрованием. Исходные комментарии технического задания и тесты сохранены.

## Запуск Node.js

Рекомендуемая среда проекта — Node.js 24. Для этих команд установка пакетов не требуется:

```bash
npm start
npm run test:logic
```

Исходные тесты задания требуют Vitest:

```bash
npm install
npm test
npm run check
```

Используйте npm. Старый yarn.lock из шаблона не используется и не копируется утилитой prepare-repositories.mjs в готовый репозиторий. После npm install сохраните новый package-lock.json. Команда npm ci применима только после его появления. Среда Vitest заменена с браузерной jsdom на node, глобальные console/fetch больше не подменяются бесконтрольно.

## Страница в браузере

```bash
npm run dev
```

Откройте http://127.0.0.1:4173/. Сборка и просмотр также не требуют установки пакетов: используются встроенные модули Node.js.

```bash
npm run build
npm run preview -- --port 4174
```

Встроенный сервер привязан к 127.0.0.1 и предназначен только для локального просмотра. Для проверки пути репозитория:

```bash
npm run preview -- --port 4174 --base /repository-check/
```

Адрес: http://127.0.0.1:4174/repository-check/. Остановка — Ctrl+C.

## Что публикуется на Pages

При сборке реально исполняется src/main.js через scripts/demo-data.mjs. Консоль и результаты записываются в dist/demo.json вместе с версией Node и временем запуска. Страница показывает эту запись, а не притворяется сервером. Браузерная песочница отдельно подписана: Web API в 54, память страницы в 55, воспроизведение записи в 56.

Workflow сначала выполняет нативные и исходные Vitest-тесты, затем сборку и публикацию. Демо после создания репозитория: https://USERNAME.github.io/REPOSITORY/ — замените шаблон после успешного deploy. Инструкция: [docs/PUBLISHING.md](docs/PUBLISHING.md).

## Структура и проверка

src/main.js — решение с исходным техническим заданием; src/__test__ — неизменённые тесты; tests — дополнительные проверки реального Node.js; scripts — CLI, сборка и сервер просмотра; web — статическая страница. [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) описывает соответствие заданию, [docs/VERIFICATION.md](docs/VERIFICATION.md) — фактические результаты и ограничения среды.
