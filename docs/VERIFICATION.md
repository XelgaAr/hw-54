# HW54 · Проверка

Дата: 25 октября 2026 года. Среда фактических запусков: Linux, Node.js v22.16.0, npm 10.9.2. Для установки актуальных зависимостей и CI проект настроен на Node.js 24; запуск на Node.js 24 в этой среде не выполнялся.

## Выполнено

`npm run test:logic`: **23 тестов, 23 пройдено, 0 ошибок**. Использован встроенный `node:test`, реальные модули проекта и моки только там, где сценарий специально проверяет недоступность/ошибку внешнего ресурса. Полный вывод: [evidence/native-tests.txt](evidence/native-tests.txt).

Также проверены синтаксис JS/JSX, существование относительных импортов, объявление внешних зависимостей, JSON/CSS и YAML workflow. Это статический аудит, а не исполнение пакетов npm. Файлы проекта не коммитились и не отправлялись в удалённый репозиторий.

## Статическая страница и Node.js

`npm start` и `npm run build` выполнены успешно на настоящем Node.js. Страница `dist` содержит запись вызовов реализованных функций, а не выдуманный результат. Исходная запись: [evidence/node-run.json](evidence/node-run.json); консоль: [evidence/demo.txt](evidence/demo.txt); сборка: [evidence/build.txt](evidence/build.txt).

Для каждого проекта выполнены 22 HTTP-проверки: HTML, CSS, JS, JSON и .nojekyll в корне и под `/repository-check/`; HEAD; 404; запрет POST; отклонение выхода за каталог; ошибочный URL; перенаправление на путь с завершающим слешем. Они прошли. Подробности: [evidence/http-checks.json](evidence/http-checks.json).

В Chromium проверены интерактивные сценарии на размерах 1440×1000 и 390×844. Ошибок страницы и горизонтального переполнения не обнаружено. Политика среды блокирует навигацию Chromium на любые URL, включая localhost (`ERR_BLOCKED_BY_ADMINISTRATOR`). Поэтому HTML/CSS/JS загружены в DOM напрямую, а fetch demo.json возвращал настоящий файл из сборки. Это проверка локального интерфейса, **не** сквозная браузерная проверка HTTP и **не** проверка опубликованного GitHub Pages. HTTP проверен отдельным клиентом. В работе 55 проверялось формирование ссылки скачивания; системная загрузка файла браузером не проверена.

Скриншоты именно этой локальной проверки: [desktop.png](evidence/desktop.png), [mobile.png](evidence/mobile.png). Машиночитаемый протокол: [browser-checks.json](evidence/browser-checks.json).
